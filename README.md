# NeStepan zapret config (best alt11)

Лучший конфиг zapret на данный момент. Оптимизирован для Discord, YouTube, Minecraft, Roblox и всего остального.

## Особенности

- **Discord** — голосовые каналы, стриминг, загрузка файлов
- **YouTube** — без лагов, полная скорость
- **Minecraft** — полная поддержка Microsoft/Xbox аутентификации (Prism Launcher, официальный лаунчер, любые)
- **Roblox** — без разрывов, все функции работают
- **Twitch, Kick, Pinterest, Reddit** и всё остальное
- Game Filter — включён (UDP)

## Установка

1. Скачай последний релиз [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)
2. Распакуй архив
3. Скопируй содержимое этой репы поверх (заменив файлы)
4. Запусти `service.bat` → установи сервис, выбери `general (ALT11)`
   Или просто запусти `general (ALT11).bat` от админа

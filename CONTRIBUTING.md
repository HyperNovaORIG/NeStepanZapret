# Contributing

1. Форкни репозиторий
2. Создай ветку: `git checkout -b feature/my-feature`
3. Внеси изменения
4. Запушь: `git push origin feature/my-feature`
5. Открой Pull Request

## Рекомендации

- Тестируй конфиг перед PR
- Описывай что изменил и почему
- Не добавляй бинарные файлы в репозиторий
